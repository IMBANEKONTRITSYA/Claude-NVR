## Не подтверждено

Интервал 2026-10-28 11:49–11:50 был введён повторно: значения были видны в обоих полях до нажатия «Найти», после клика поля очистились, счётчик остался 200, первая строка показывала 12:01:34. Это подтверждённый симптом при автоматизированном вводе, но пока не доказанный дефект приложения: `Archive.tsx` использует контролируемые React-поля `value={f.date_from/date_to}` с `onChange`, а запрос строится из состояния `f` и конвертирует границы через `localInputToUtc`. Инструмент мог выставить видимое значение, не обновив внутреннее состояние; параметры запроса не были сняты. Пункт остаётся открытым до ручного ввода или проверки запроса.

Отчёт по времени для конкретного события не подтверждён из-за пустой таблицы событий. Расписание отчётов с доставкой по электронной почте не запускалось.

## Найденное расхождение: старый FPS на выключенных камерах

На странице «Мониторинг» одновременно показаны 0/0 потоков записи и 0 камер в сети, однако в таблице «Аналитика по камерам» остаются значения FPS 3.18 и 0.96 у двух строк. Все источники в списке камер выключены. Это повторное проявление D12: FPS не очищается/не скрывается после остановки источника. Архивная запись при этом не запускается.

Сводные счётчики мониторинга согласуются с выключенным состоянием источников. Самостоятельная проверка живого видео и нагрузка 16 H.265 плиток не выполнялись: физические камеры оставлены выключенными.

## Проверка фильтров камер, live и архива

Все проверки ниже были только чтением/поиском в интерфейсе. Активность источников не менялась: 49 камер выключены, потоков нет.

- Список камер: поиск по IP 192.168.105.65 и отдельно по ID 32 в обоих случаях возвращает одну строку — DS-I103 №32. Очистка текста возвращает 49 строк.
- Группа по местоположению 192.168.105.65 оставляет одну камеру; возврат к «Все локации (49)» восстанавливает полный список.
- Live: кнопки сетки показывают 1, 4, 9 и 16 плиток. В сетке 16 камер переход меняет диапазон с 1–16 на 17–32 из 49 (стр. 2/4), «Назад» возвращает на стр. 1. Фильтр по IP оставляет только DS-I103; очистка возвращает первые 16 камер. Во всех плитках было сообщение, что поток не заведён в MediaMTX, поэтому декодирование живого видео и расход памяти при воспроизведении не проверялись.
- Архив: выбор камеры №1 показывает записи только с ID #1. Тип «Непрерывная запись» возвращает continuous; совместный фильтр оставляет записи этой камеры. Сброс двух фильтров возвращает 200 строк; в них присутствуют 44 разных ID камер.
- Фильтр времени был повторно проверен через автоматизированный ввод: до «Найти» поля отображали 2026-10-28 11:49–11:50, после клика оба очистились, счётчик остался 200, первая запись — 12:01:34 (за пределами интервала). Однако это не доказывает дефект приложения: поля `datetime-local` управляются состоянием React, а в браузерной автоматизации видимое DOM-значение не гарантирует, что обработчик `onChange` обновил состояние. В `Archive.tsx` запрос строится из состояния `f` и переводит время через `localInputToUtc`; фактические параметры запроса в этом прогоне не сняты. Нужна ручная проверка клавиатурного ввода или просмотр параметров запроса. Сам плеер не проверен — сегмент не выбирали.
