# Повторная веб-проверка FaceWatch — 2026-11-11

## Область и состояние стенда

Проверялась локальная интеграционная сборка из PR #160–173 через встроенную вкладку Codex. Docker Desktop показывал проект `claudenvr` запущенным; Docker CLI из оболочки не получил доступ к named pipe движка, поэтому состояние сервисов оценивалось по ответам самого приложения.

На момент проверки в приложении заведено 49 камер, все 49 выключены, онлайн-источников 0. Настройки физических камер не менялись, новые источники не создавались, камеры не перезапускались. В БД оставались 6 661 сегмент архива; события/персоны на дашборде — 0.

## Проверено через веб-интерфейс

- Повторный вход из просроченной сессии успешен: открылся дашборд, в журнале есть `POST /api/auth/login` с HTTP 200.
- Дашборд загрузил карточки и графики; при пустых событиях показывает 0 событий и 0 персон.
- Страница камер показывает 49 заведённых и 0 онлайн; все переключатели «Активна» выключены.
- Мониторинг показывает загрузку CPU/RAM, диск, доступность Redis и число архивных сегментов; приложение сообщает 0 активных потоков, 6 661 сегмент, 3.7 ГБ архива. Есть предупреждение о виртуальном диске WSL2.
- «Камеры в реальном времени» и «Стена распознавания» открываются. При выключенном источнике плитка сообщает «Поток не заведён в медиасервере»; стена показывает пустое состояние.
- Архив загружается и выводит до 200 строк с временем, камерой, типом и длительностью.
- Экспорт появлений CSV и XLSX через страницу «Отчёты» возвращает HTTP 200. CSV содержит UTF-8 BOM; XLSX является валидной книгой OOXML. В обеих выгрузках заголовок времени — «Время (Etc/UTC)». В таблице нет событий, поэтому сверить время конкретного события с архивом нельзя.
- Журнал аудита показывает успешный вход и обе успешные выгрузки; на первой странице 50 из 286 записей.

## Не подтверждено

Автоматизированный ввод интервала архива 11:49–11:50 очищался после нажатия «Найти», при этом счётчик оставался 200 и в результатах были строки за пределами интервала (вплоть до 12:01). После заполнения значения в самом DOM не сохранились как состояние формы. Это может быть ограничением автоматизированного ввода либо дефектом интерфейса; считать фильтр работающим нельзя. Оставлен незакрытым до проверки ручным вводом в браузере.

Отчёт по времени для конкретного события не подтверждён из-за пустой таблицы событий. Расписание отчётов с доставкой по электронной почте не запускалось.

## Найденное расхождение: старый FPS на выключенных камерах

На странице «Мониторинг» одновременно показаны 0/0 потоков записи и 0 камер в сети, однако в таблице «Аналитика по камерам» остаются значения FPS 3.18 и 0.96 у двух строк. Все источники в списке камер выключены. Это повторное проявление D12: FPS не очищается/не скрывается после остановки источника. Архивная запись при этом не запускается.

Сводные счётчики мониторинга согласуются с выключенным состоянием источников. Самостоятельная проверка живого видео и нагрузка 16 H.265 плиток не выполнялись: физические камеры оставлены выключенными.
