Механизм этого известен с цикла 42 и структурен: чужая сессия работает в
своей `fix|feat|perf/*`-ветке, и рабочая ветка не меняется вовсе от её
старта до первого мерджа. Проверка по возрасту коммита рабочей ветки
слепа к самому типичному состоянию живой сессии — и одновременно
срабатывает на самом надёжном признаке её завершения (коммит-отчёт).
**Она ошибается в обе стороны и обе стороны предсказуемы.**

Отсюда — уточнение к рекомендации, уже высказанной циклом 42:
формулировку шага 1 стоит свести к проверке по открытым PR с базой на
рабочей ветке, а «свежий коммит» из критерия остановки убрать или
инвертировать (терминальный коммит-отчёт — признак **освободившейся**
ветки, а не занятой). Это не отменяет рекомендацию №1 issue #56
(распределённый лок с heartbeat и TTL) — она остаётся единственной, что
закрывает вопрос полностью.

## 4. Поправка: штамп `[session:...]` на `b5687a1` не терялся

Комментарий цикла 42 к issue #56 (раздел «Попутно: отказал сам механизм
обнаружения») утверждает, что коммит `b5687a1` — отчёт цикла 40 — не
несёт штампа `[session:...]`, и приводит проверку:

```bash
git log -1 --format=%B b5687a1 | grep -c 'session:'   # заявлено: 0
```

Фактический результат этой же команды — **1**. Штамп на месте, отдельной
строкой в теле сообщения:

```
[session:2026-08-18T061600Z]
```

Проверить:

```bash
git log -1 --format=%B b5687a1 | grep -n 'session:'
# 30:[session:2026-08-18T061600Z]
```

Похоже на проверку по `%s` (заголовку) вместо `%B` (полному телу): в
заголовок штамп действительно не выносится — ни на этом коммите, ни на
любом другом коммите-отчёте в ветке, это штатная раскладка. Вывод цикла
42 о пересечении циклов 40 и 41 остаётся в силе — он опирается на
таймлайн, а не на этот пункт; отпадает только обвинение самого механизма
штампов в отказе. Это существенно: рекомендация №4 issue #56 («ставить
штамп и в заголовок PR») мотивировалась в том числе этой уликой, а
единственный аргумент за неё — что штамп в заголовке избавляет от чтения
тела коммита, — остаётся, но уже без истории «механизм однажды не
сработал».
