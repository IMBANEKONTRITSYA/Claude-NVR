ЗАЧЕМ ЭТОТ ФАЙЛ
Ветки ниже полностью влиты в claude/pensive-brown-28588t. Squash-merge,
поэтому `git branch -r --merged` их не показывает: содержимое в ветке есть,
но коммит ветки не предок. Автоматика удалить их не может — `git push
--delete` из песочницы получает HTTP 403 от прокси 17 циклов подряд,
отдельного delete_branch среди доступных GitHub MCP-инструментов нет.

ВАЖНО ПРО ПРОВЕРКУ
По выводу `git push --delete` судить нельзя: при отказе он печатает
"Everything up-to-date", хотя ветка жива. Проверять надо
`git ls-remote --heads origin <branch>` — уточнение цикла 18,
перепроверено циклом 23: отказ воспроизводится, ветка остаётся.

КАК УДАЛИТЬ (вручную, с машины с правами на репозиторий)

    # все разом из этого файла
    sed -n '/^СПИСОК/,$p' docs/reviews/ORPHANED_BRANCHES.txt \
      | grep -E '^(fix|feat|test|perf|docs|chore|review)/' \
      | xargs -n 20 git push origin --delete

    # либо по одной:  git push origin --delete <branch>
    # либо через веб-интерфейс: Branches -> All branches -> корзина

После удаления файл можно очистить — следующий цикл соберёт список заново,
если ветки снова накопятся.
