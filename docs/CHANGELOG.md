## Цикл аудита 6 — 2026-08-04

### Добавлено
- ONVIF-клиент событий движения/присутствия людей (ТЗ 18.7): подписка
  PullPoint, WS-Security UsernameToken, классификация топиков — камеры с

  с автоматическим откатом на MOG2 при сбое (#23).

### Исправлено
- **P0**: `/hls/` (живое видео) проксировался в MediaMTX вообще без
  проверки авторизации — любой с сетевым доступом к nginx мог смотреть
  любую камеру, просто перебирая `cam{id}`, без логина. Закрыто через
  nginx `auth_request` + существующий JWT-контракт (#22).
- CI: порог покрытия (`--cov-fail-under`) поднят с 55 до 68 — фактическое
  покрытие (71%) с цикла 5 ушло далеко вперёд порога, регресс покрытия не
  ловился (#21).

## Разработка Tier-1 (до начала циклов автономного аудита)

Дальнейшая разработка после MVP — в один непрерывный поток коммитов,
без отдельных PR/тегов:

- Профили производительности («экономный»/«стандартный»/«максимальный»),
  двухпоточная работа с камерами (основной поток + субпоток для
  детекции), мониторинг системы (ТЗ 18, ТЗ 12).
- Нейросетевой апскейл лиц (GFPGAN) как отдельный сервис, поиск похожих
  лиц по фото через pgvector.
- Ручное создание персон, заметки, watchlist с Telegram-оповещениями.
- pgvector HNSW-индексы, лимит попыток входа (rate limiting логина),
  постраничная выдача на сервере, экспорт журнала аудита.
- Дашборд в реальном времени, бесконечная прокрутка стены
  распознавания, полноэкранный режим.
- Живые bounding box'ы на LiveGrid, реальные имена в ленте, тепловая
  карта часов пик.
- HLS-стриминг живого видео, ROI-редактор поверх реального кадра
  камеры, ROI-маска в детекции, фоновая DBSCAN-перекластеризация.

## MVP — исходная версия

- Базовый функционал: подключение IP-камер по RTSP, мозаичный просмотр,
  детекция и распознавание лиц (InsightFace), видеоархив по событию,
  карточки персон, роли пользователей (bcrypt), развёртывание на
  Windows через Docker Compose одной командой (`start.bat`).
